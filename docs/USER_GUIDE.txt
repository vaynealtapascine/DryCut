DRYCUT USER GUIDE
=================

WHAT IT DOES
------------
DryCut removes image backgrounds on your Windows PC. Processing is local: your images are not uploaded. The original file is never changed.

OPEN OR QUEUE IMAGES
--------------------
- Drag one or several images onto the DryCut window, or select "Choose images". The file picker supports multi-select.
- Press Ctrl+V (Cmd+V on macOS) to paste an image straight into the queue. This works both for a file copied in Explorer/Finder and for raw image data copied from another app. Paste does nothing while a text box has focus, so it never interferes with typing.
- Supported formats: PNG, JPEG, WebP, BMP, and TIFF.
- You can also right-click an image in Explorer after enabling the optional context-menu item in Settings. On Windows 11, the item may appear under "Show more options".

QUEUE AND GALLERY
-----------------
- Images process one at a time in queue order. You can add more while the queue is running.
- The queue header shows how many images remain and estimates the total time after the first image establishes a baseline.
- Completed results remain in the same panel as a gallery and are loaded again when DryCut starts.
- DryCut displays at most 100 queue/gallery entries at once. Use Newer and Older to move between pages of completed results.
- Select any result to preview it. Each completed entry has one-click Copy and Delete actions.
- Gallery copies are temporary and are deleted on startup, or during periodic cleanup while the app stays open, once they are older than 30 days. Use Save or Save as for any result you want to keep permanently.

IMPROVE A RESULT
----------------
Model:
- Fast & accurate: included and recommended for most images.
- Highest quality: a larger optional download intended for hair, fur, fine structures, and busy backgrounds.

Edge detail:
- None: keep the model mask unchanged.
- Balanced: light cleanup for general use.
- Soft: gently soften rough edges.
- Detailed: spend more time preserving fine edge detail.

Newly queued images use the current choices. To run the selected image again with the current choices, select "Reprocess". This does not re-import the image; it reuses the file already in the queue or gallery.

PANEL MODE
----------
- Select "Panel mode" in the header to shrink the window to a narrow strip you can park beside another app while you work. Select the expand icon in the panel header to switch back to the full window.
- The panel keeps the queue/gallery, the before/after preview, and the Quality/Edges controls, arranged vertically to fit the narrower width.
- The pin icon in the panel header keeps DryCut on top of other windows. Select it again to turn that off.
- Panel mode remembers the width you last resized it to, and reopens in the same mode you left it in.

EXPORT
------
- Copy: places transparent PNG data and a compatible bitmap on the Windows clipboard.
- Save: uses the behavior chosen in Settings.
- Save as: always asks for a location.

Settings offers three Save behaviors:
- My DryCut folder: Pictures\DryCut by default.
- Beside the original image.
- Ask every time.

Results are PNG files so transparency is preserved. If a name is already used, DryCut adds a number rather than overwriting it.

EXPLORER CONTEXT MENU
---------------------
Open Settings, scroll to the Explorer option, enable it, and save. This is a per-user setting and does not need administrator access. Disable the same option to remove it.

OPTIONAL STRONG MODEL
---------------------
Open Settings and select "Download highest quality". The download is approximately 467 MB. DryCut checks a pinned SHA-256 hash before installing it. A partial or invalid download is deleted.

KEYBOARD SHORTCUTS
------------------
- Ctrl+O (Cmd+O on macOS): choose images.
- Ctrl+S (Cmd+S on macOS): save.
- Ctrl+N (Cmd+N on macOS): choose more images.
- Ctrl+V (Cmd+V on macOS): paste an image from the clipboard. Ignored while a text box has focus.
- Escape: cancel the image currently processing.

PRIVACY
-------
- Image decoding, model inference, edge cleanup, previewing, copying, and saving happen locally.
- The only network feature is the explicit optional-model download.
- Settings are stored under %LOCALAPPDATA%\DryCut.
- Temporary processed-image gallery copies are stored under %LOCALAPPDATA%\DryCut\history and are removed after 30 days.
- Each gallery entry also records the file path of the original image, so the gallery can still show it beside the
  result after a restart. This path stays on your PC, is never uploaded, and is deleted with the entry.

TROUBLESHOOTING
---------------
- If the app says the included model is missing, reinstall or fully extract the portable ZIP.
- If the stronger model cannot download, check the internet connection and try again. The fast model still works offline.
- If a result is poor, try Highest quality and Detailed edge cleanup.
- If copying does not preserve transparency in a particular program, use Save as and import the PNG.
- Unsigned builds may trigger Windows SmartScreen. Verify the installer checksum from the release notes before running it.

UNINSTALL
---------
Use Windows Settings > Apps > Installed apps > DryCut > Uninstall. The uninstaller removes installed files, the Explorer menu entry, and the temporary gallery. Your manually exported images are left alone.
